# PDF Label

报告要合并一大堆附件 PDF，合并完还得在每页左上角标上“附件1-1”“附件1-2”……偏偏有些页面还得跳过去，编号又不能断！

难道要在 Adobe Acrobat 里一页一页插文字、调字体、对齐位置吗？

**做不到做不到！(╯°□°）╯**

于是就有了 **PDF Label**！

把已经在 Acrobat 里整理好的 PDF 拖进来，勾选需要编号的页面，调整一下字体和位置，剩下的交给它就好。超级方便！

**[▶ 打开 PDF Label](https://seaout.github.io/pdf-label-studio/)**

## 能干什么？

- **自由编号：** 前缀、序号、后缀随便搭，支持补零、递增和单独修改。
- **想标哪页就标哪页：** 输入页码范围，或者在预览时直接勾选。跳过的页面不占编号。
- **拖入 PDF：** 支持多个文件，分别设置、批量导出。
- **所见即所得：** 实时预览，拖动文字调整位置，也能用毫米精确定位。
- **字体自由搭配：** 中文、西文字体分别设置，支持本机字体、字号、颜色和真实粗体。
- **样式模板：** 调好一次，下次直接用。
- **本地处理：** PDF 在浏览器内处理，无须把文件上传到服务器。

整理 PDF 的事情交给 Acrobat，繁琐的编号工作就交给 PDF Label 吧！
